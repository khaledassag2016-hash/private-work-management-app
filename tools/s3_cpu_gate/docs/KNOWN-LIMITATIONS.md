# KNOWN-LIMITATIONS

1. **مانع البناء الحالي:** لا يحتوي بيئة التنفيذ على PowerShell 7، لذلك لم يمكن تشغيل Pester أو PSScriptAnalyzer أو المحاكاة الكاملة للمنسق PowerShell. لا يجوز اعتماد أو تسليم الحزمة النهائية.
2. لا يمكن إثبات حالة حساب المستخدم أو الخطط أو Billing أثناء بناء الحزمة؛ الإثبات يتم لاحقًا عند التشغيل.
3. Cloudflare Billing Profile API موثقة رسميًا لكنها Deprecated. غيابها أو نقص Billing Read يوقف التشغيل قبل إنشاء الموارد.
4. تغيّر إصدارات CLI أو JSON schema قد يفعّل fail-closed blocker بدل المتابعة.
5. سياسات مؤسسة أو proxy أو TLS inspection أو منع OAuth قد تعطل تسجيل الدخول.
6. حذف Google Cloud Project يبدأ حالة حذف قابلة للاستعادة ولا يعني محوًا فوريًا؛ التقرير يثبت `DELETE_REQUESTED`.
7. لا تضمن CLR محو كل نسخة داخلية من string فورًا؛ التصميم لا يحفظ الأسرار، ويزيل المراجع ويصفّر buffers القابلة للتصفير كأفضل جهد.
8. Workers Logs قد تتأخر أو تسقط أحداثًا. أي مجموعة ناقصة تؤدي إلى `CPU GATE: FAIL`.
9. اختبارات aud/iss/exp السحابية تستخدم إعدادات اختبار مؤقتة ثم تعيد نشر النسخة الصارمة؛ يجب إثبات إزالة كل test control.
10. عند وجود أكثر من حساب Cloudflare متاح، تتوقف الحزمة بدل مطالبة المستخدم باختيار تقني أو التخمين.
11. المسار ثابت إلى `C:\Users\MC\Desktop\1`; إذا لم يكن متاحًا تتوقف الحزمة ولا تختار بديلًا.
