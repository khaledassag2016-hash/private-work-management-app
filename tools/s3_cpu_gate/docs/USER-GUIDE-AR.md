# دليل المستخدم — غير معتمد للتشغيل بعد

**لا تشغّل أي ملف من مصدر البناء الحالي.** لم تُنتج الحزمة النهائية لأن بوابتي Pester وPSScriptAnalyzer لم تُنفذا.

بعد اعتماد الحزمة النهائي إشرافيًا فقط، سيكون الاستخدام المقصود:

1. نزّل ملف التشغيل المعتمد.
2. شغّل الملف؛ سينشئ `C:\Users\MC\Desktop\1` تلقائيًا.
3. وافق على تسجيل الدخول في صفحات GitHub وGoogle وCloudflare الرسمية.
4. اقرأ الملخص العربي واختر متابعة أو إلغاء.
5. عند النهاية ارفع ZIP الموجود في `artifacts` إلى جلسة S3.

## ماذا أفعل إذا توقف البرنامج مستقبلًا؟

- أعد تشغيل `START.cmd`.
- سيستأنف من آخر مرحلة آمنة إذا لم تكن هناك أسرار سحابية لازمة.
- إذا حدث الانقطاع بعد إنشاء موارد Live، سينفذ تنظيفًا آمنًا ثم يطلب تشغيلًا جديدًا بدل إعادة استخدام أسرار غير محفوظة.
- لا تحذف `state.json` أثناء تشغيل غير مكتمل.
- ارفع `blocker-report.zip` عند ظهور مانع.
- عند ظهور بطاقة أو Billing أو خطة مدفوعة اختر إلغاء فورًا.
