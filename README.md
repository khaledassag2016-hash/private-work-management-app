تطبيق ويب خاص لإدارة الأعمال الأكاديمية والمحاسبة والمتابعة بين شخصين.

- المستودع: خاص.
- المرحلة الحالية: **S1 — تأسيس المشروع وإدارة التنفيذ**.
- المرجع الحاكم الوحيد: ملف Word المعتمد الذي يُعاد بناؤه محليًا في `docs/APPROVED_REQUIREMENTS.docx`.
- حُفظت بايتاته دون تعديل في ثمانية أجزاء نصية داخل `docs/source_parts/` بسبب قيد واجهة رفع الملفات الثنائية.
- بصمة المرجع SHA-256: `6cb2e99449deb287b2008baf23e091efe45a89f3edfb15df721c933271d6b65b`.
- التكلفة الإلزامية: **صفر**. لا تعتمد أي خدمة مدفوعة، ولا بطاقة بنكية، ولا ترقية تلقائية.

## قواعد حاسمة

1. لا تُرفع بيانات العملاء الحقيقية أو ملفات الأعمال إلى GitHub.
2. لا يُعدّل الفرع `main` بعد تأسيسه إلا عبر Pull Request ومراجعة.
3. كل مرحلة تعمل في فرع مستقل وبنطاق ومعايير قبول محددة.
4. لا تُسلّم مرحلة قبل تشغيل فحوصها وتحديث `PROJECT_STATE.md`.
5. عند التعارض، تسود وثيقة المتطلبات المعتمدة، ثم سجل القرارات المؤرخ.

## إعادة بناء المرجع والتحقق

```bash
python scripts/reconstruct_requirements.py
python scripts/validate_foundation.py
```

ينجح الأمر الأول فقط إذا أعاد ملف DOCX بالبصمة المعتمدة نفسها، ويتحقق الأمر الثاني من تغطية `FR 30/30` و`AC 14/14` و`P 7/7` ومن الملفات الحاكمة ومؤشرات الأسرار الأساسية.

التفاصيل: `docs/ROADMAP.md` و`docs/PROJECT_RULES.md` و`docs/DEFINITION_OF_DONE.md`.
