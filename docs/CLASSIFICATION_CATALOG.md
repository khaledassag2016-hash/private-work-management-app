# كتالوج التصنيفات الأولي

القوائم قابلة للتوسع من داخل التطبيق دون تعديل برمجي. رموز المقررات قرائن مساعدة فقط، ولا تُفسر دون الجامعة واسم المقرر.

## أنواع الأعمال

- رسالة ماجستير كاملة.
- جزء أو فصل من رسالة ماجستير.
- خطة بحث / Proposal.
- مراجعة أدبيات / Literature Review.
- منهجية / Research Design and Methodology.
- استبانة / Google Form / أداة دراسة.
- تحليل إحصائي / SPSS / تدريب SPSS.
- بحث أكاديمي.
- بحث أو مشروع تخرج.
- مقال أو ورقة علمية للنشر.
- ملخص / Abstract / Conclusion.
- نقد بحث أو رسالة.
- عرض تقديمي / Presentation.
- بوستر.
- Handout.
- واجب / Assignment / Homework.
- مناقشة / Discussion.
- اختبار / Quiz / Final Exam.
- تقرير، تقرير سريري، أو تقرير تدريب تعاوني.
- دراسة حالة.
- دراسة جدوى / Business Plan.
- مشروع مقرر / Group Project.
- مذكرة قانونية، صحيفة دعوى، أو مذكرة جوابية.
- ترجمة أو تلخيص.
- سيرة ذاتية.
- حضور مناقشة.
- تنسيق أو إعادة صياغة أو تعديل.
- جمع مراجع أو استشهاد بدراسات سابقة.
- تحليل بيانات / Business Data Analytics.
- تصميم أو مشروع تقني.
- رسوم نشر أو خدمة مرتبطة بالنشر.

## التخصصات والمجالات

- القانون.
- الشريعة والفقه والدراسات الإسلامية.
- الإدارة العامة وإدارة الأعمال.
- الموارد البشرية والسلوك التنظيمي والقيادة.
- المحاسبة.
- المالية والاقتصاد.
- التسويق والتجارة الإلكترونية.
- إدارة المشاريع والعمليات وسلاسل الإمداد.
- التربية والمناهج وعلم النفس التربوي.
- اللغة العربية والأدب.
- اللغة الإنجليزية واللسانيات.
- التمريض والرعاية الصحية والصحة العامة.
- الصيدلة والسموم والكيمياء الحيوية.
- الأحياء والميكروبيولوجي.
- الطب والعلوم الطبية والأشعة.
- الهندسة الميكانيكية والكهربائية والمدنية والطاقة.
- الرياضيات والإحصاء.
- تقنية المعلومات ونظم المعلومات والأمن السيبراني وتصميم الويب.
- العلوم الاجتماعية والأنثروبولوجيا.
- موضوعات عامة أو متعددة التخصصات.

## أمثلة رموز المقررات

| الرمز أو البادئة | المجال المرجح | القيد |
|---|---|---|
| MGT | إدارة | مثل MGT301 وMGT311 وMGT401. |
| ACCT | محاسبة | مثل ACCT101 وACCT301. |
| ECON | اقتصاد | مثل ECON101 وECON201. |
| FIN | مالية | مثل FIN101 وFIN201 وFIN401. |
| ECOM | تجارة إلكترونية | وصف المقرر يختلف حسب الجامعة. |
| MIS / IT / SYS | نظم معلومات وتقنية معلومات | قد يشمل مشاريع ودراسات حالة تقنية. |
| PHC / HCM | صحة عامة أو إدارة صحية | يتطلب تأكيد الجامعة والمقرر. |
| NURS | تمريض | مثل NURS563 وNURS564. |
| BIOL | أحياء | مثل BIOL103. |

## الدول الأولية

- السعودية: الغالبية الكبرى.
- الإمارات: نسبة متزايدة، خاصة في الأعمال القانونية بالفترة الأخيرة.
- الأردن: عدد ضئيل جدًا.
- دول أخرى: تُضاف دون تعديل برمجي.
