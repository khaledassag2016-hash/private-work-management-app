## نطاق النظام

- تطبيق خاص لشخصين فقط: جالب الأعمال ومنفذ الأعمال.
- لا يستبدل واتساب ولا يخزن ملفات الأبحاث والرسائل.
- يدير العملاء، الأعمال، المتابعة، الأسعار، الدفعات، التسويات، البحث، التحليل والتصدير.
- العملة الأساسية: الريال السعودي.
- النسبة الافتراضية: 30% للشخص الأول و70% للشخص الثاني، مع استثناءات موثقة.
- كل معلومة مالية أو تنفيذية قابلة للتتبع زمنيًا ولا تُستبدل دون حفظ التاريخ والسبب.

## حالات دورة حياة العمل

| الحالة | المعنى |
| --- | --- |
| طلب جديد | وصلت فكرة العمل ولم يبدأ تقديرها |
| قيد دراسة المطلوب | الشخص الثاني يراجع المطلوب ويجمع معلومات أولية لتقدير السعر |
| يحتاج تسعير | لم يُحدد السعر بعد |
| بانتظار رد العميل | تم إرسال السعر أو الاستفسار ولم يصل تأكيد |
| يحتاج متابعة من الشخص الأول | طلب غير محسوم قد يضيع إن لم تتم متابعته |
| متفق عليه | وافق العميل على السعر والنطاق |
| قيد التنفيذ | بدأ العمل الفعلي |
| بانتظار معلومات من العميل | تعذر التقدم بسبب نقص البيانات |
| بانتظار مراجعة العميل أو المشرف | تم تسليم مرحلة ويُنتظر الرد |
| تعديل مطلوب | ورد تعديل ضمن الاتفاق أو خارجه |
| متوقف مؤقتًا | العمل غير ملغى لكنه متوقف |
| ملغى قبل التنفيذ | لم يبدأ تنفيذ فعلي |
| متوقف بعد تنفيذ جزئي | تم إنجاز جزء ثم انسحب العميل أو توقف |
| مكتمل | أنجز العمل كاملًا |
| مسلم | تم التسليم النهائي |
| مغلق ماليًا | تم سداد كامل المستحقات وإتمام التسوية |
| غير محصل | لم يدفع العميل رغم وجود عمل منجز |
| محصل جزئيًا | دفع جزءًا وبقي جزء |
| مؤرشف | منتهٍ لكنه يبقى قابلًا للبحث والتحليل |

| إجمالي قيمة الأعمال | مجموع الأسعار الحالية للأعمال الداخلة في فترة التسوية |

## القرارات المعتمدة

| الرقم | البند | القرار المعتمد |
| --- | --- | --- |
| P-01 | إجمالي اشتراكي الموقعين | تم اعتماد إجمالي قيمة الاشتراكين الحالي بمبلغ 136.5 ريال سعودي. وتكون قيمة كل اشتراك قابلة للتعديل عند تغير سعره أو إلغاء الاشتراك، على أن تسري القيمة الجديدة من تاريخ التغيير دون تعديل التسويات السابقة المعتمدة. |
| P-02 | طريقة تحميل الاشتراكات | يدفع الشخص الثاني قيمة الاشتراكات فعليًا، بينما يتحمل الطرفان تكلفتها مناصفة. لذلك يُضاف نصف إجمالي قيمة الاشتراكات إلى مستحق الشخص الثاني، ويُخصم النصف نفسه من مستحق الشخص الأول ضمن التسوية. |
| P-03 | توزيع رسوم التحويل | يدفع الشخص الأول رسوم التحويل فعليًا، بينما يتحمل الطرفان تكلفتها مناصفة. لذلك يُضاف نصف رسم التحويل إلى مستحق الشخص الأول، ويُخصم النصف نفسه من مستحق الشخص الثاني ضمن التسوية. |
| P-04 | أساس احتساب النسب | تُحتسب نسبة 30% للشخص الأول و70% للشخص الثاني من السعر الحالي المعتمد للعمل، بعد تطبيق الزيادات أو التخفيضات المرتبطة بالعمل نفسه، وقبل تطبيق الاشتراكات ورسوم التحويل. وبعد احتساب الحصتين، تُجرى تسوية المصاريف المشتركة بصورة مستقلة. |
| P-05 | صلاحيات الحذف وتعديل السعر | لا يجوز الحذف النهائي لسجل العمل؛ ويُنفذ طلب الحذف على صورة إلغاء أو أرشفة مع بقاء السجل محفوظًا وقابلًا للتتبع. ويتطلب إلغاء أو أرشفة أي سجل عمل، أو تعديل سعر العمل، موافقة الطرفين. ويجب الاحتفاظ بسجل يوضح القيمة السابقة والقيمة الجديدة وتاريخ التعديل والطرف الذي طلبه وموافقة الطرف الآخر. |
| P-06 | بيانات العميل الأساسية | تُحفظ بيانات العميل الأساسية، وتشمل: اسم العميل، والجامعة، والتخصص، والدولة. ويُربط العميل بجميع أعماله السابقة والحالية وسجل التعاملات المالية والملاحظات المتعلقة به. |
| P-07 | استيراد البيانات التاريخية | يُؤجل استيراد البيانات التاريخية إلى مرحلة مستقلة تشمل التنظيف والمراجعة والتصنيف، ولا يمنع ذلك بدء تصميم النظام الجديد. ولا تُعتمد الحسابات القديمة كأرصدة نهائية إلا بعد مراجعتها. |

| المتبقي | السعر الحالي ناقص الدفعات المعتمدة. |
