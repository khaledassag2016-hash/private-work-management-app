# S2 approval protocol

1. Present recommendation, alternatives, evidence and tests.
2. Wait for explicit user approval of one architecture.
3. Update the same branch and PR; do not open another PR.
4. Change ADR from Proposed to Accepted and add a dated D decision only after approval.
5. Re-run S1/S2 tests and complete self-review.
6. Return the PR to the general supervision session for independent review; do not merge here.
