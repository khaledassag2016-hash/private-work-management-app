# خارطة الطريق

| المرحلة | الاسم | المخرج الرئيسي |
| --- | --- | --- |
| S1 | تأسيس المشروع وإدارة التنفيذ | الوثائق الحاكمة، التتبع، الأمن، الجودة، خارطة الطريق، وقوالب التسليم. |
| S2 | اختيار المعمارية المجانية | مقارنة موثقة للتقنيات والتحقق من صفر تكلفة وعدم الحاجة إلى بطاقة بنكية وخطة نقل البيانات. |
| S3 | الهوية وقاعدة البيانات وسجل التدقيق | تسجيل دخول Email/Password لحسابين فقط، نموذج البيانات الأساسي، قواعد الوصول، والتدقيق، بعد اجتياز بوابة CPU الإلزامية على Workers Free. |
| S4 | العملاء والأعمال والتصنيفات | العملاء، الأعمال، الحقول، الحالات الأساسية، التصنيفات، والتنبيهات المرتبطة بتاريخ العميل. |
| S5 | المتابعة والمراحل وتاريخ العناوين | سجل الأحداث، المراحل، العناوين السابقة، الإلغاء والأرشفة دون حذف، وفصل حالة التنفيذ عن التحصيل. |
| S6 | الأسعار وطلبات الموافقة | الحركات السعرية، الموافقة الثنائية على تعديل السعر، النسب والاستثناءات، وإعادة الحساب؛ ويُحسم Q-001 قبل تنفيذ صلاحية تغيير النسبة. |
| S7 | الدفعات والتسويات والمصاريف | الدفعات والأقساط والمتبقي والاشتراكات ورسوم التحويل والتسوية الشهرية؛ ويُحسم Q-002 وأي قرار بشأن Q-003 وQ-004 قبل السلوك المرتبط بها. |
| S8 | البحث والتقارير والتصدير | البحث والتصفية والتحليلات وتصدير Excel RTL والتنبيهات الزمنية، مع إعادة اختبار ظهور الأرشيف تاريخيًا. |
| S9 | تجربة الاستخدام للهاتف والكمبيوتر | تصميم عربي RTL متجاوب، وضوح الحالات، سهولة الاستخدام وإتاحة الوصول. |
| S10 | اختبار التكامل والنسخ والاستعادة | اختبارات شاملة، تعارض التعديلات، الأداء، النسخ الاحتياطي والاستعادة وإصدار تجريبي. |
| S11 | تنظيف واستيراد البيانات التاريخية | مرحلة مستقلة بعد استقرار النظام، دون اعتماد الحسابات القديمة قبل المراجعة. |

## قواعد الانتقال

- لا تبدأ مرحلة تعتمد على سابقتها قبل دمج السابقة أو اعتماد واجهاتها بعقد مكتوب.
- لا يبدأ تنفيذ سلوك مرتبط ببند `Q` غير محسوم قبل تحويله إلى قرار `D` معتمد.
- S11 مستقلة ولا تمنع بناء النظام الجديد.
- مراجعة التكامل في S10 تعيد اختبار جميع AC-01 إلى AC-14.

## بوابة دخول S3 الإلزامية

بعد دمج S2 وموافقة مستقلة على إنشاء بيئة تجريبية مجانية، تبدأ S3 بقياس تحقق Firebase ID Token فعليًا على Cloudflare Workers Free. تشمل القياسات cache hit وcache miss وشهادة X.509 والتحقق من RS256 والمطالبات وقائمة السماح.

- الحد الحاكم: 10ms CPU لكل استدعاء على Workers Free.
- إذا تكرر تجاوز الحد أو إنهاء الاستدعاء بصورة قابلة لإعادة الإنتاج، يتوقف S3 ويعاد القرار إلى جلسة الإشراف العام أو يختار بديل مجاني موثق من S2.
- يمنع استخدام Workers Paid أو تفعيل Billing أو ربط بطاقة لمعالجة التجاوز.
- لا تنفذ وظائف S3 الأخرى قبل اجتياز هذه البوابة وتوثيق نتيجتها.
