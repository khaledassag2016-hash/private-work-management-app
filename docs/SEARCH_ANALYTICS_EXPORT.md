# البحث والتحليلات والتصدير

## البحث والتصفية

- البحث باسم العميل أو جزء منه.
- البحث بعنوان العمل الحالي أو أي عنوان سابق.
- البحث بنوع العمل أو التخصص أو المادة أو رمز المقرر.
- البحث بالجامعة أو الدولة.
- البحث بنطاق سعري أو شهر أو سنة.
- البحث بحالة التنفيذ أو حالة التحصيل أو علامة العميل.
- البحث في نص الملاحظات وسجل الأحداث.
- إظهار الأعمال المشابهة وأسعارها السابقة للمساعدة في التسعير دون فرض سعر تلقائي.

## التحليلات

- عدد الأعمال شهريًا وسنويًا والتراكم الكلي.
- إجمالي قيمة الأعمال والمقبوض والمتبقي.
- توزيع الأعمال حسب النوع والتخصص والدولة والجامعة.
- أكثر العملاء تكرارًا والمتأخرون وغير المسددين.
- عدد التعديلات المجانية والمدفوعة لكل عمل أو عميل.
- متوسط ونطاق أسعار الأعمال المتشابهة مع تواريخها؛ لا رقم وحيد مضلل.
- مقارنة المستحق بالمقبوض الفعلي.
- الوقت بين الاتفاق والسداد عند توفر التواريخ.

السعر مؤشر مساعد فقط ولا يجوز استخدامه وحده لتحديد نوع العمل.

## متطلبات Excel

- اتجاه الورقة والنص من اليمين إلى اليسار.
- ترتيب التبويبات بما يناسب الاستخدام العربي.
- عناوين واضحة وترويسات ثابتة وتنسيق أرقام وتواريخ مناسب.
- تقرير شهري بالأعمال والأسعار والمدفوع والمتبقي والنسب والمصاريف والتسوية والرصيد المرحل.
- ملف عمل واحد ببيانات العميل والعمل والعناوين والمراحل والأحداث والسعر والدفعات والحالتين.
- سجل متابعة بالتاريخ والنوع والوصف والمستخدم.
- تقرير عملاء بالأعمال والمدفوع والمتبقي والعلامات.
- تحليل تصنيفي حسب النوع والتخصص والدولة والجامعة والفترة.
- القيم تأتي من حسابات النظام، لا من صيغ يدوية هشة.
