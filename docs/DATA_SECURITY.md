# أمن البيانات والخصوصية

## تصنيف البيانات

- **محظور في GitHub:** أسماء العملاء الحقيقية، أرقام الاتصال، ملفات العمل، المراسلات، المدفوعات الحقيقية، بيانات الدخول، مفاتيح الخدمات، ملفات `.env`، النسخ الاحتياطية الحقيقية.
- **مسموح:** كود المصدر، مخطط قاعدة البيانات، وثائق فنية، بيانات اختبار وهمية، قوالب فارغة.

## ضوابط الحسابات

- حساب مستقل لكل شخص، ولا حسابات عامة.
- مبدأ أقل صلاحية.
- تعطيل إنشاء الحسابات العام؛ إضافة الحسابين إداريًا فقط.
- تسجيل العمليات الحساسة مع هوية المستخدم والوقت والقيم السابقة والجديدة.

## الأسرار

- الأسرار في إعدادات الخدمة أو الاستضافة، لا داخل المستودع.
- فحص الملفات قبل كل دمج بحثًا عن كلمات المرور والرموز والمفاتيح.
- عند تسرب سر: إلغاؤه وتدويره فورًا ثم إزالة الأثر من التاريخ وفق إجراء موثق.

## النسخ الاحتياطي

- النسخ الاحتياطي منفصل عن GitHub.
- يجب اختبار الاستعادة فعليًا قبل اعتبار النسخ الاحتياطي صالحًا.
- التصدير بصيغة مفتوحة لتجنب الارتباط بخدمة واحدة.

## الحوادث

أي اشتباه في وصول غير مصرح يوقف التغييرات الحساسة، ويُراجع سجل التدقيق، وتُغيّر بيانات الدخول، ويُوثق ما حدث دون إخفاء.
