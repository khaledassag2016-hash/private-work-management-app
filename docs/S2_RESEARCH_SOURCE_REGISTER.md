# S2 — سجل مصادر البحث

تاريخ التحقق: 2026-08-03. استخدمت المصادر الرسمية المباشرة فقط، وروابطها التفصيلية موجودة في ملفات المقارنة والتكلفة والأمن. لا تستخدم نتيجة بحث عامة أو مقال طرف ثالث بوصفه دليلًا حاكمًا.

| المزود | نطاق المصادر الرسمية |
|---|---|
| Cloudflare | Workers pricing/limits، D1 pricing/limits/import-export، Zero Trust setup |
| Firebase | Spark billing، Authentication users/limits، Firestore quotas/export |
| Supabase | Pricing، pausing، backups، billing FAQ |
| Appwrite | Pricing، billing limits، 2026 changelog |
| Google Apps Script | Web app access، quotas، LockService |
