# قواعد التعامل مع البيانات التاريخية

## الغرض

البيانات القديمة تُستخدم لفهم الأنماط وبناء التصنيفات والرجوع إلى الأعمال والأسعار السابقة، لكنها لا تُعتمد تلقائيًا أرصدة صحيحة؛ لأن بعض الأعمال انسحبت، وبعض الأسعار تغيرت، وبعض التواريخ بلا سنة، وبعض العناوين مختصرة.

## الاستخدام المسموح

- استخراج أنواع الأعمال والتخصصات ورموز المقررات والدول والجامعات المتكررة.
- استخراج العملاء والأعمال السابقة لتسهيل البحث عن الأسعار.
- اكتشاف حالات رفض الدفع والتخفيض والخسارة والعمل المجاني والعمل لطرف واحد والنسب المختلفة والتعديلات المتكررة.
- إنشاء سجل أولي يحتاج مراجعة قبل اعتماده.

## قواعد التنظيف

1. لا تُفترض السنة عند غيابها؛ يُوسم التاريخ بأنه غير مكتمل ويحتاج مراجعة.
2. لا يكفي عنوان عام مثل Assignment أو Poster أو Test للتصنيف النهائي.
3. السعر صفر يحتاج سببًا صريحًا: غير مسعر، مجاني، ضمن اتفاق أكبر، رفض دفع، أو خطأ.
4. تُفصل صفوف الأعمال عن صفوف المجاميع والتسويات والملاحظات.
5. لا تُجمع المدفوعات أو الأرصدة القديمة تلقائيًا قبل اعتمادها.
6. يُحفظ النص الأصلي ومصدر الصف وحالة المراجعة لمنع فقد المعنى.
7. لا تدخل الحسابات القديمة في الرصيد الحالي إلا بعد مراجعة واعتماد صريحين.

## قرار التنفيذ

الاستيراد مرحلة S11 مستقلة، ولا يمنع بناء النظام الجديد. يجب أن يكون قابلًا للتراجع وأن ينتج تقريرًا بالمقبول والمرفوض والمعلق.
