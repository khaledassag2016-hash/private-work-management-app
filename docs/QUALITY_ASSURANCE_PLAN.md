# خطة ضمان الجودة

## مستويات التحقق

1. **فحص ثابت:** بنية الملفات، التنسيق، الأسرار، اكتمال المعرفات والروابط.
2. **اختبارات وحدة:** المعادلات وقواعد الحالات والصلاحيات الصغيرة.
3. **اختبارات تكامل:** الواجهة مع قاعدة البيانات والمصادقة وسجل التدقيق.
4. **اختبارات قبول:** السيناريوهات AC-01 إلى AC-14.
5. **اختبار رجعي:** عدم كسر الوظائف المعتمدة.
6. **اختبار يدوي:** الهاتف والكمبيوتر، RTL، الرسائل والتنبيهات.

## الأدلة المطلوبة

- أمر الاختبار وتاريخه ونتيجته.
- عدد الاختبارات الناجحة والفاشلة والمتجاوزة.
- لقطات أو سجلات عند الحاجة، دون بيانات حقيقية.
- ربط كل فشل بIssue أو إصلاح قبل الدمج.

## موانع التسليم

فشل أمني، خطأ حسابي، فقد تاريخ، متطلب غير مغطى، اعتماد خدمة مدفوعة، أو عدم إمكانية الاستعادة يمنع الدمج.
