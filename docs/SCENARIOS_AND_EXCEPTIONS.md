# السيناريوهات والاستثناءات المعتمدة

هذه السيناريوهات مستخرجة من المرجع المعتمد، وتُستخدم لاشتقاق اختبارات التكامل والقبول. لا تستبدل ملف Word.

| المعرف | السيناريو | السلوك المطلوب |
|---|---|---|
| S-01 | رسالة بسعر أساسي ثم إضافات | عمل واحد بسعر أساسي 1500 ثم +200 للاستبانة و+100 لإضافة أخرى؛ يظهر التسلسل والسعر الحالي 1800. |
| S-02 | تغيير عنوان الرسالة | يصبح العنوان الجديد رسميًا، ويُحفظ القديم وتاريخ التغيير وسببه، وتضاف تكلفة التغيير إن كان خارج الاتفاق. |
| S-03 | مرحلة ثم تتحول إلى رسالة كاملة | تُربط الخطة أو المرحلة بالعمل الأكبر دون فقد سعرها أو تاريخها. |
| S-04 | عرض أو تحليل مستقل | يُحدد هل العرض أو التحليل عمل مستقل لطالب آخر أم تابع لرسالة أو بحث. |
| S-05 | طلب يحتاج تسعير ولم يرد العميل | يُحفظ ضمن «يحتاج متابعة» مع تاريخ آخر تواصل حتى لا يضيع الجهد الأولي. |
| S-06 | إلغاء قبل التنفيذ | يبقى الطلب والعميل والمتابعة محفوظين، ولا يدخل كعمل منجز. |
| S-07 | توقف بعد تنفيذ جزئي دون دفع | يُسجل المنجز والسعر والمدفوع صفر والمتبقي كاملًا، وتُحدث علامة العميل وفق الوقائع. |
| S-08 | اكتمال العمل ودفع جزئي | عمل بسعر 1700 ودفع 1000 يبقى متبقيه 700 وحالته محصل جزئيًا. |
| S-09 | سداد متأخر أو أقساط | تُضاف كل دفعة بتاريخها حتى يصبح المتبقي صفرًا، مهما تباعدت الدفعات. |
| S-10 | خصم نادر | يُسجل التخفيض حركة سالبة بسبب واضح، دون إرسال مبلغ ما دام العميل لم يدفع الزيادة. |
| S-11 | تعديلات مجانية متكررة | تُسجل كتعديلات تنفيذية بقيمة صفر لإظهار مرات العودة وحجم الجهد. |
| S-12 | عميل له عدة أعمال | لكل عمل عنوان وسعر وحالة ومدفوعات مستقلة رغم اشتراكها في العميل نفسه. |
| S-13 | عميل يعود بعد مشكلة سابقة | يظهر تنبيه مبني على سجل موثق لعدم الدفع أو الدفع الجزئي أو الحظر قبل اتفاق جديد. |
| S-14 | عمل مجاني أو بقيمة صفر | يجب تحديد سبب الصفر: مجاني، ضمن اتفاق أكبر، خطأ تسجيل، رفض دفع، أو لم يُسعر بعد. |

## قاعدة الاختبار

لا يكفي اختبار المسار المثالي؛ يجب أن تشتمل خطط المراحل S4 إلى S10 على هذه الحالات حيث تنطبق، مع ربط كل نتيجة بسجل تدقيق وحساب متوقع.
