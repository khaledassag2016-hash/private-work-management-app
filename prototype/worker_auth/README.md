# Worker authentication proof

هذا نموذج محلي لمسار التحقق من Firebase ID Token داخل Cloudflare Worker باستخدام Web Crypto، دون اتصال بخدمة سحابية فعلية.

## التحقق الإلزامي

- قبول `alg=RS256` فقط.
- اشتراط `kid` غير فارغ ومطابقته بشهادة Google X.509 ذات المعرّف نفسه.
- جلب الشهادات من endpoint Firebase الرسمي وتخزينها مؤقتًا حسب `Cache-Control: max-age`.
- إعادة الجلب عند انتهاء المدة، ومحاولة تحديث عند ظهور `kid` جديد.
- استخراج SubjectPublicKeyInfo من شهادة `BEGIN CERTIFICATE` ثم التحقق من التوقيع.
- التحقق من `aud` و`iss` و`exp` و`iat` و`auth_time` و`sub`.
- اشتراط `sub` غير فارغ ثم مطابقته بقائمة السماح الخاصة بالشخصين.

## دليل X.509 المحلي

يولد اختبار Node شهادة self-signed مؤقتة من نوع `BEGIN CERTIFICATE` ومفتاح RSA مؤقتًا بواسطة OpenSSL. تمر الشهادة داخل استجابة `GooglePublicKeyCache` الوهمية، ويستخدم المفتاح الخاص لتوقيع token؛ ثم يثبت الاختبار استخراج المفتاح العام من الشهادة والتحقق من التوقيع. تحذف الملفات المؤقتة ولا يرفع أي مفتاح خاص أو سر إلى GitHub.

## Fail closed

كل مسار API خاص يمر عبر `requirePrivateApiAuthorization` قبل أي قراءة أو كتابة. أي خطأ في الرمز أو الشبكة أو الشهادة أو المفتاح أو التوقيع أو المطالبات أو قائمة السماح يؤدي إلى الرفض؛ لا fallback ولا guest mode.

D1 مرتبطة بالـWorker عبر binding داخلي فقط. لا endpoint عام لقاعدة D1، ولا بيانات اعتماد لها في الواجهة، ولا مسار يتجاوز Worker.

## حدود الإثبات وبوابة S3

استجابة endpoint الرسمي وتدوير الشهادات الحقيقيان ممثلان بـmock، ولم تنشأ خدمة Firebase أو Cloudflare. بعد موافقة مستقلة على البيئة، تبدأ S3 بقياس المسار الكامل على Workers Free. إذا تكرر تجاوز حد CPU البالغ 10ms يتوقف التنفيذ وتعود المعمارية إلى بوابة القرار أو بديل مجاني؛ يمنع Workers Paid أو الفوترة.
